# AI Flower

Find out what type of AI flower you are. The questions, scoring, 3D flower, stem and PNG/SVG flower cards run in your browser. Nothing is collected on the questionnaire.

## Publish or update on GitHub

1. Unzip the download and open the `ai-flower-github` folder.
2. Upload every file inside it to the top level of your public `ai-flower` repository. Replace matching filenames. Do not upload the ZIP or the enclosing folder.
3. Commit to `main`.
4. In Settings → Pages, choose Deploy from a branch, `main`, and `/ (root)`, then Save. Later commits publish automatically.

Your website address is normally `https://YOUR-USERNAME.github.io/ai-flower/`.

`index.html` must be at the repository's top level beside the JavaScript and CSS files. All files belong to the same release; replace them together.

## Questions and editing

`data.mjs` contains the published wording. `questions.html` and `edit-questions.html` list every question and provide Edit buttons. Further edits made there are saved locally in the browser until the draft is applied to the published site. Questionnaire responses are separate and remain in the current tab's memory.

`scoring.html` explains the scores, flower and research basis. `offline.html` is a self-contained copy. The form has no account requirement, analytics, database or paid hosting dependency.
